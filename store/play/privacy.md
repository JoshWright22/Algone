# Privacy form answers: Google Play Data safety (Algone Browser)

Algone collects no user data and has no server. The policy is at https://joshwright22.github.io/Algone/privacy/.

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | **No**, if the final build still has no analytics or crash reporting. |
| Is all user data encrypted in transit? | Answer only if you declare data. The app loads `https:` pages only. |
| Do you provide a way for users to request data deletion? | No data is held off the device. Uninstalling removes it. |
| Contains ads | No |
| App access | All functionality available without special access |
| Target audience | 18 and over, or 16 and over if you prefer. Do not select children. |
| Privacy policy URL | https://joshwright22.github.io/Algone/privacy/ |

## What leaves the device

Nothing is sent by Algone itself except these plain requests:

- The daily rules download, to GitHub Pages. No identifier, no cookies.
- Custom feed requests, only to feeds the user adds.
- Wikipedia, only if the user opts in. It asks for a random article summary.

Those hosts see an IP address, as with any web request. Algone never receives that data.

Sites you open inside the app handle your data under their own policies, as in any browser. Logins are held by the web view on the device.
